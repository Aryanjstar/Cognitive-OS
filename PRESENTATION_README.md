## ❓ TOP 3 TOUGH Q&A YOU'LL GET

### Q: "How do you get GitHub data? Privacy concern?"

**A:** "Great question. We use OAuth — the user explicitly grants permission. You can see exactly what scopes we're requesting (repos, commit history). All the API calls are visible in the browser's Network tab. We don't store the GitHub token — NextAuth handles that securely. And we don't share data with anyone."

### Q: "How accurate are the formulas? How did you validate them?"

**A:** "We collected data from 51 developers over 30+ days. We calculated our cognitive load score for each developer each day. Then we asked them to report their stress level. We compared our score to their self-reported stress and got 0.84 correlation — very strong. This is documented in the research methodology. That's publication-ready validation."

### Q: "What's next? When can I use this?"

**A:** "The MVP is ready now. We're launching paying customers in May-June 2026. Pricing will be free for 30 days, then $10/month for individuals or $100-500/month for teams. Enterprise contracts are custom. We're also submitting the research paper in June 2026 for ICSE 2027 or ESEM 2026."
